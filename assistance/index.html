Assistance / Support

Assistance

Écrivez à contact@objectivemethod.fr en précisant la version d’AgentHQ, votre version de macOS, le fournisseur concerné et les étapes du problème. Ne transmettez ni clés API, mots de passe, ni journaux ou prompts confidentiels.

Connecter votre environnement

Installez Codex ou Claude Code et démarrez une session. Dans AgentHQ, choisissez le fournisseur. Vérifiez le dossier proposé dans la fenêtre explicative, puis cliquez sur Continuer et sur Autoriser la lecture dans la fenêtre macOS.

Le dossier habituel est ~/.codex pour Codex et ~/.claude pour Claude Code. Si votre installation utilise un autre chemin, choisissez un autre emplacement. Vous pouvez retirer l’accès depuis le menu AgentHQ.

AgentHQ affiche l’activité locale disponible ; il ne lance pas d’agents. Les comptes ou abonnements Codex/Claude ne sont pas inclus. Les formats des données locales peuvent évoluer : signalez toute incompatibilité.

Support

Email contact@objectivemethod.fr with your AgentHQ version, macOS version, provider and steps to reproduce. Do not send API keys, passwords, confidential logs or prompts.

Connect your environment

Install Codex or Claude Code and start a session. Choose the provider in AgentHQ, check the suggested folder, click Continue, then Allow reading in the macOS dialog. Usual locations: ~/.codex and ~/.claude. Choose another location for a customized setup. Remove access in the AgentHQ menu.

AgentHQ displays available local activity and does not run agents. Codex/Claude accounts or subscriptions are not included. Local data formats can change; contact support if compatibility breaks.
